# Coca-Cola: Icono Global (1886–2026)

Presentación web interactiva de **6 diapositivas** basada en `CocaCola.pptx`, lista para subir a **GitHub** y publicar como sitio web gratuito en **GitHub Pages**.

## Contenido de la Presentación

1. **01 / 06 · Portada — Coca-Cola: Icono Global**: Introducción general (1886–2026) con acceso rápido a cada bloque temático.
2. **02 / 06 · Sus Inicios**: El origen en Atlanta (Dr. John S. Pemberton, 1886), la caligrafía Spencerian (1887), la fundación corporativa (1892), el sistema de franquicias (1899) y la estrategia del precio fijo de `5¢` durante 70 años.
3. **03 / 06 · Modelo de Negocio y Finanzas**: Ingresos netos anuales (`$47.9B`), margen bruto del concentrado (`61.6%`), `2.200 M` de raciones diarias, cadena de valor con `+200` socios embotelladores y `+30M` puntos de venta, y gráfico de rentabilidad financiera (`61.6%`, `28.7%`, `27.4%`).
4. **04 / 06 · Marketing, Historia y Cultura**: Botella Contour (`1915`), Santa Claus de Haddon Sundblom (`1931`), campaña *Hilltop* (`1971`) y *Comparte una Coca-Cola* (`2011`).
5. **05 / 06 · Sostenibilidad, Salud y Controversias**: Reformulación baja/sin calorías (`68%` del portafolio), reposición hídrica (`+100%`) y envases `rPET`, junto con los desafíos ambientales y de salud pública.
6. **06 / 06 · Legado Atemporal**: 140 años refrescando el mundo sobre tres pilares: identidad inconfundible, capilaridad logística y evolución sostenible.

## Cómo subirlo a GitHub y activarlo en GitHub Pages

1. Descomprime este archivo `.zip` en tu computadora.
2. Crea un repositorio público nuevo en [GitHub](https://github.com/new) (por ejemplo, `coca-cola-presentacion`).
3. Haz clic en **Add file → Upload files**, arrastra todo el contenido descomprimido (`index.html`, `README.md`, `CocaCola.pptx` y la carpeta `assets/`) y presiona **Commit changes**.
4. Entra a **Settings → Pages** en tu repositorio.
5. En **Branch**, selecciona `main` y `/ (root)`, y haz clic en **Save**.
6. En unos segundos tu presentación estará publicada en `https://TU-USUARIO.github.io/coca-cola-presentacion/`.
